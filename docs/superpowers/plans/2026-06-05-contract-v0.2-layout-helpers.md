# Contract v0.2 Layout Helpers + WorkspaceManager Refactor — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `@agentrium/contract` the single source of truth for the on-disk workspace/run directory layout, and refactor agentrium core onto it — so a separate consumer (agentrium-ui) can discover runs without duplicating layout knowledge.

**Architecture:** Add pure (no `fs`) path-layout helpers to `@agentrium/contract` (bump to 0.2.0). Refactor `src/workspace/manager.ts` to build the workspaces dir via the contract and expose a new `getRunsDir(name)`; replace every hand-built `path.join(getWorkspacesDir(), <ws>, "runs")` in the CLI with `getRunsDir(<ws>)`. No behavior change — the resolved paths are identical.

**Tech Stack:** TypeScript (ESM, Node ≥ 24), npm workspaces, Vitest. The contract is consumed as a built workspace package (`npm run build` builds it first).

**PREREQUISITE (read first):** This plan extends `packages/contract`, which exists only on the Plan 1 branch (PR #20 — `feat: live run telemetry + control channel`). Execute this plan on a branch based on **main *after* PR #20 is merged** (so `packages/contract` is present). Do NOT start it on a main that lacks `packages/contract`.

**Invariant:** Resolved filesystem paths must be byte-for-byte identical to today (`~/.agentrium/workspaces/<name>/runs/<runId>/...`, or `$AGENTRIUM_HOME/...` if set). This is a pure refactor + a new env override; existing runs must remain discoverable.

export const RUN_ID_PREFIX = "run_";

export function defaultAgentriumHome(): string {
